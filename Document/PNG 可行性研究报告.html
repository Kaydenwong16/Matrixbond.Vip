本章基于三方协议文件、会议纪要与市场公开资料，对本项目进行全要素可行性论证。项目以巴新财政部主权担保为信用底座，以拟设立的国家控股主权基金为发行主体，首期发行人民币35亿元熊猫债，募集资金以离岸人民币形式交付，专项用于开发区九通一平及基础设施建设，并通过循环发债机制保障资金长期稳定。报告认为项目政策可行、市场可行、结构可行、财务可行，执行层面需对主权担保落地、监管审批与政局窗口进行前置管控（详见第十一章结论）。

本报告就巴布亚新几内亚（以下简称"巴新"）经济特别开发区（以下简称"开发区"）在中国境内银行间债券市场发行人民币熊猫债（首期规模人民币35亿元、约合5亿美元、期限3—5年）的可行性进行全面、系统的论证。报告基于三方于2026年4月12日签署的《合作协议》（协议编号：VG-PNG-2026-001）、三次工作会议纪要（2026年4月7日、4月11日、4月12日）及公开市场资料，从项目背景、市场环境、政策框架、合作模式、发行方案、还款能力、风险控制、长期战略、经济效益与实施计划等维度展开分析。

1
核心结论一（政策窗口明确）

2026年一季度中国熊猫债市场发行规模达882.35亿元，同比激增101.45%，创历史同期新高；市场存量4761.78亿元，同比增长35.54%。监管机构持续简化发行注册流程、优化资金使用规则，政策红利集中释放。中国正在主动寻找合格发债标的，有主权担保的熊猫债基本能够获得中国人民银行总行批准。

2
核心结论二（项目条件具备）

本项目具备"主权担保＋主权基金发行主体＋资源反担保＋国家级开发区用款场景"的完整要素组合，与埃及（2023年，35亿元）、巴基斯坦（2026年5月，17.5亿元，亚投行与亚开行联合部分担保）、哈萨克斯坦主权财富基金（2026年）等主权级发行案例在结构上高度可比，巴新有望成为南太平洋地区首个发行熊猫债的国家。

3
核心结论三（融资成本优势显著）

当前熊猫债票面利率普遍处于1.94%—2.51%的低位区间，中美利差持续倒挂，较境外美元融资预计可节省100—200个基点的财务费用。按5亿美元、3年期测算，每年利息支出约可较美元债融资节约1500万—1750万美元。

4
核心结论四（还款能力有实物支撑）

开发区已与巴新林业部、贸易部及土地主协会达成一致，设立500万立方米木材加工基地（年产值预估约25亿美元），作为发债反担保资产；巴新国家黄金储备（100—200吨黄金存单）及丰富油气、矿产、林业资源构成国家层面信用底座。综合测算，首期35亿元人民币债券的偿债覆盖率充足。

5
核心结论五（风险可控但需前置管理）

项目主要风险包括主权信用评级偏低（标普B-、穆迪B2）、巴新政局换届不确定性、主权担保文件法律效力、监管审批进度及项目执行合规管理，本报告第七章逐项提出应对措施。

6
核心结论六（总体判定：项目可行）

建议三方按"先授权定框架、再申报获额度、后发行促落地"的路径，在2026年内完成主权基金设立、主权担保文件落实与中国监管申报，力争2026年四季度至2027年一季度实现首期发行。

第一章 项目总论

1.1 项目背景

巴布亚新几内亚是位于南太平洋西部的重要岛国，人口约1000万，坐拥世界级油气、矿产、森林与渔业资源，是"全球南方"的重要成员。长期以来，巴新基础设施建设资金缺口巨大，传统融资渠道（美元外债、多边机构贷款）已难以满足发展需求，亟需开辟低成本、可持续的新型融资路径。

2026年是中巴新建交50周年，两国已建立全面战略伙伴关系，共建"一带一路"合作持续深化。2026年2月，中国进出口银行董事长与巴新副总理等高层举行工作会谈，官方首次明确提及"人民币业务合作"；2026年3月，进出口银行融资支持的巴新国家电网二期项目顺利竣工。双边金融合作正从"项目融资"向"资本市场合作"升级，为巴新主权主体进入中国债券市场创造了历史性机遇。

在此背景下，巴新经济特别开发区管理委员会（甲方）委托宏鑫企业控股有限公司（乙方）主导、广东企沅工程管理有限公司（丙方）协同，推动开发区以"国家主权担保＋主权基金发行主体"的方式在中国境内发行人民币熊猫债，募集资金专项用于开发区九通一平及基础设施建设，并以此推动巴新从"资源国家"向"资本国家"战略转型。

第二章

第二章 项目背景与立项必要性

2.1 巴新国家概况与经济形势

巴布亚新几内亚国土面积46.3万平方公里，人口约1000万，拥有得天独厚的自然资源禀赋：已探明黄金、铜、油气、镍钴、森林与渔业资源储量位居全球前列，是全球重要的资源出口国。国民经济高度依赖资源部门，油气（LNG）、矿业、农林渔占GDP比重较大，出口收入的绝大部分来源于资源产品。

经济基本面方面：巴新GDP总量约130亿基那（约合220亿美元），近年实际GDP增速约4.7%，在太平洋岛国中处于较高水平。政府财政收入与资源价格高度相关，近年受益于国际大宗商品价格中枢上移，财政状况有所改善。巴新政府持续推动经济多元化，将经济特别开发区建设、基础设施互联互通、本土加工增值（如木材本地化加工）作为国家战略方向。

从信用基本面看，国际评级机构对巴新的主权评级为：标普（S&P）B-、穆迪（Moody's）B2，处于投机级区间，但展望持续改善。需要指出的是，巴新的偿债能力与其评级并不完全匹配：其一，巴新外债规模总体可控，偿债记录良好；其二，国家拥有海量资源资产（黄金、油气、矿产、森林），"资源货币化"空间巨大；其三，500万立方米木材加工基地等实物资产的现金流创造能力远高于评级所反映的水平。

2.2 中巴新双边关系与金融合作深化

中巴新两国于1976年建交，2026年迎来建交50周年。2018年两国建立全面战略伙伴关系，巴新成为首个同中国签署共建"一带一路"合作谅解备忘录的太平洋岛国。中国已连续多年成为巴新最大贸易伙伴和主要投资来源国，在能源、矿产、基础设施、农业等领域合作成果丰硕。

2.3 开发区基本情况与资金需求

巴布亚新几内亚经济特别开发区由巴新政府批准设立，开发区管理委员会（甲方）为法定管理机构，吕长春先生任开发区主席。开发区法人地位来源于巴新财政部正式授权设立，具备签署及履行协议的完全权利能力与行为能力。开发区定位为巴新国家级经济增长极，规划首期开发10平方公里，参照中国蛇口工业园区（2.4平方公里起步区四通一平）、苏州工业园区（8平方公里起步区三年完成）的成熟经验推进开发建设。

开发区当前面临的核心约束是启动资金缺口：

  1. 巴新政府虽已批准设立开发区，但受财政能力所限，计划拨款未能到位，开发区尚未正式挂牌运营，前期办公费用由吕主席个人垫付；
  2. 开发区九通一平（道路、供水、供电、通信、燃气、排水、排污、供热、场地平整）及基础设施建设投资强度大，需要大额、长期、低成本资金；
  3. 巴新本地资本市场发育不足，美元融资成本高企，传统多边机构贷款审批周期长、附加条件多，难以匹配开发区"三年基本完成九通一平"的节奏。

在此背景下，发行人民币熊猫债成为解决开发区启动资金的最优路径之一。

2.4 立项必要性分析

（一）基础设施资金缺口的现实需要

开发区九通一平及配套基础设施建设资金需求量大，首期35亿元人民币（约合5亿美元）如能落地，将直接解决开发区"从0到1"的启动资金问题，支撑首期10平方公里土地开发，形成可出让、可招商的成熟产业用地。

（二）融资渠道多元化与降成本的需要

巴新外债以美元为主，受美国利率周期影响大。人民币熊猫债票面利率处于1.94%—2.51%低位区间，较美元债节省100—200个基点，且人民币币值相对稳定、中长期存在升值趋势，以人民币计价发行有利于降低巴新的综合融资成本与汇率错配风险。

（三）人民币国际化的国家战略契合

中国政府正大力推动人民币国际化与债券市场高水平开放，熊猫债是境外机构持有比例最高的中国债券品种。巴新作为"一带一路"共建国家和南太平洋重要国家，发行熊猫债既服务于本国发展，也契合中国推动人民币在主权融资领域使用的政策方向，属于"互利共赢"的战略性项目，容易获得政策支持。

（四）示范效应与区域影响力

巴新有望成为南太平洋地区首个发行熊猫债的国家，对周边岛国具有显著示范效应，同时提升开发区及巴新在国际资本市场的能见度，为后续常态化人民币融资（循环发债、多银行多批次发行）奠定信用基础。

（五）推动资源货币化与长期转型

以发债为起点，项目将逐步推进主权基金运作、资源银行设立与木材等大宗商品的人民币结算，助力巴新实现从"资源国家"向"资本国家"的战略转型，这是巴新国家战略层面的长期价值。

第三章

第三章 熊猫债市场环境与政策分析

3.1 熊猫债概念与市场发展历程

熊猫债指境外机构（包括外国政府及其机构、国际开发机构、境外金融机构及非金融企业）在中国境内银行间债券市场或交易所债券市场发行的、以人民币计价的债券。自2005年首单发行以来，熊猫债市场经历了起步探索（2005—2013）、重启扩容（2014—2018）、规则完善（2019—2023）与爆发增长（2024年至今）四个阶段，发行主体从国际开发机构扩展至主权国家、金融机构与跨国企业，已成为人民币国际化的核心载体之一。

截至2026年3月末，熊猫债市场存量达4761.78亿元，同比增长35.54%。中国银行作为市场领军者已连续十二年蝉联熊猫债承销商榜首，累计协助超过80家境外优质客户发行熊猫债350余支、总规模超过7000亿元，覆盖欧洲、北美洲、非洲、南美洲、中亚五大洲，其中以主承销商身份参与的主权熊猫债达19支，境外主权机构承销覆盖率高达90%——这为拟由中国银行主承销的本项目提供了强有力的机构能力背书。

3.2 2026年市场爆发式增长

2026年一季度，熊猫债市场出现爆发式增长：全市场发行规模达882.35亿元，同比激增101.45%，创历史同期新高。市场热度延续了2025年以来的上行趋势，发行节奏明显加快，发行主体日益丰富，主权发行人、多边开发机构与跨国企业同台竞技。

市场火热的核心驱动力包括：

  1. 成本优势显著：境内融资成本低于境外，熊猫债票面利率普遍处于1.94%—2.51%的低位区间；
  2. 政策红利释放：监管机构简化发行注册流程、优化资金使用规则、对境外机构投资者利息收入给予税收优惠；
  3. 人民币资产吸引力上升：全球投资者增配人民币资产，人民币相对美元保持稳定偏强，提升了人民币计价发行的性价比；
  4. 发行人结构多元化：新兴市场主权国家、主权财富基金等新类型发行人密集入场，形成示范效应。

3.3 利率环境与融资成本优势

当前中美利差持续倒挂，境内人民币融资成本显著低于境外美元融资成本。2026年熊猫债票面利率普遍集中在1.94%—2.51%区间，而同期美元债及巴新可比的境外主权债融资成本显著更高。按本项目5亿美元（35亿元人民币）发行规模测算：

  • 若以2.5%—3.0%的人民币票面利率发行，较5.5%—6.0%的美元融资成本，每年可节省利息支出约1500万—1750万美元（即100—200个基点的利差红利）；
  • 3年期存续期内累计节约融资成本约4500万—5250万美元；
  • 若考虑人民币对美元的中期升值趋势，实际还本付息压力将进一步下降。

战略结论：当前是利用国际资本市场窗口发行熊猫债的有利时机，对巴新而言可有效优化债务结构、降低综合融资成本。

第五章 发行方案设计

5.1 发行主体设立（主权基金）

技术结论：开发区管理委员会属行政机构，不具备独立法人资格、无法自负盈亏，不能直接作为发债主体申报。经多方论证，本项目采用"主权基金"作为发行主体的方案：

  1. 由甲方牵头，依据巴新相关法律法规，在巴新境内注册设立主权基金（国家控股基金），全部股权归属巴新财政部，不设个人股份；
  2. 主权基金在金融法规层面不要求经营年限与业绩记录，只需财政部部长签字和主权担保文件即可满足发债主体合规要求，大幅节省时间与文件准备成本；
  3. 主权基金以国家主权担保为信用基础，规避了开发区缺乏财务报表、审计记录等数据的问题——"一个主权担保就全部解决了"；
  4. 基金注册成立后，完善董事会治理结构（见4.4节），同步开立境内外账户。

替代与补充方案：若直接设立财政部下属公司程序复杂（需经使馆、首相府、外交部、首相、财政部全链条审批），可采取变通方案——由财政部以正式公文委托开发区作为熊猫债资金借款人与管理人，开发区在当地注册"熊猫债基金管理公司"等专项公司承接资金管理与项目执行。借款人（巴新政府）与管理人（开发区）的法律关系以财政部长正式函件明确。

5.2 主权担保安排

主权担保是本次发行获批的关键。安排要点如下：

  1. 担保形式：由巴新财政部出具正式书面主权担保文件，形式可包括国家主权信用担保、黄金/物资担保、财政收入担保等，须明确担保标的类型、金额及相关权责，并确保符合中国金融监管机构要求；
  2. 落实节点：担保文件须在发行申报前取得并随申报材料提交；
  3. 法律保障：同步推动巴新议会或相关立法机构通过与发债、主权基金设立相关的必要法案或决议，确保担保与发行全流程合法合规；
  4. 反担保安排：开发区以500万立方米木材加工基地及相关资源资产为政府借款提供反担保，形成"政府担保—开发区反担保—资源现金流"的闭环；
  5. 前置确认：财政部长已就提供担保作出明确表态，并与吕主席有书面函件往来；本报告建议在申报前由甲方取得财政部正式担保文件正本及翻译公证件。

5.6 承销与经办安排

主承销银行：中国银行。理由如下：

  1. 中国银行连续十二年蝉联熊猫债承销榜首，累计协助80余家境外客户发行350余支、总规模超7000亿元，境外主权机构承销覆盖率90%，是境外机构发行熊猫债的"首选伙伴"；
  2. 中国银行参与了19支主权熊猫债发行，涵盖埃及（非洲首单、国际开发机构担保模式）、巴基斯坦（南亚首单）等与巴新可比的项目，主权项目经验丰富；
  3. 具体经办机构为中国银行驻巴新代表处/新西兰分行（巴新尚无中国商业银行分支机构，新西兰分行可承担账户与业务经办职能）；
  4. 中国银行PNG总代表郑小红对本项目高度积极，将其视为代表处核心业绩机会，可为主承销资格与内部流程提供直接推动；
  5. 中国银行香港分行及其证券公司可作为承分销与结算渠道的补充。

5.7 信用评级

中国不认可境外评级机构（标普、穆迪、惠誉等）对境内债券的评级结论。本次熊猫债评级由承销银行委托中国境内具有资质的评级机构（如中诚信国际信用评级有限公司，人民银行体系下主要评级机构）开展。在主权担保增信下，债项评级有望获得AA+至AAA的较高评级（参照：巴基斯坦在亚投行/亚开行部分担保下获得AAA债项评级），从而有效降低票面利率、扩大投资者基础。

5.8 计价结算与资金用途

  1. 计价：以在岸人民币计价发行；
  2. 结算：募集资金最终以离岸人民币形式交付甲方，甲方可在国际市场自由使用；
  3. 兑换纪律：三方承诺不将发债所得离岸人民币大规模转换为美元。该承诺符合央行外汇管理导向（避免重演巴西、阿根廷货币互换后离岸人民币被兑换成美元偿还外债、冲击外汇储备的教训），是获得政策优惠额度的关键；基建支出以人民币计价支付本身具有经济合理性（转美元反而产生汇率损失）；
  4. 资金用途：募集资金专项用于开发区九通一平及基础设施建设、开发区分期开发、主权基金运营等，全部资金纳入开发区用款计划表管理，接受承销银行与监管机构对资金用途的核查；
  5. 汇率视角：美国正施压人民币升值，以人民币计价对发债方（巴新）有利——人民币升值意味着未来还债实际成本下降。

5.9 循环发债（短债接长）机制

鉴于熊猫债单期期限有限（一般3年，最长5年），本项目确立循环发债（短债接长）机制：

  1. 在本期债券到期前3个月，三方共同启动续发新债工作；
  2. 乙方主导协调其他具有承销资格的商业银行（如中国建设银行等）续发新债，所得资金优先偿还本期到期债务，保障资金长期稳定可用；
  3. 首次通过中国银行发行成功后，可请建设银行（可能经纽约或新西兰分行）发行第二期，不同银行分别申请额度，分散单点依赖；
  4. 核心原则："循环的是货币，不碰产品"——确保两期债券之间不断档（断一天都不行），资源银行的建立有助于解决资金衔接问题；
  5. DFI多品种统一注册模式可为循环发行提供制度便利。

第十一章 结论与建议

11.1 可行性结论

综合本报告分析，巴布亚新几内亚经济特别开发区熊猫债发行项目总体可行：

  1. 政策上可行：央行鼓励熊猫债发行并主动寻找合格标的，有主权担保的项目获批确定性高；注册制与DFI模式提升发行效率；
  2. 市场上可行：2026年一季度市场发行882.35亿元（+101.45%），票面利率1.94%—2.51%处于低位，主权级发行屡获超额认购；
  3. 结构上可行："主权担保＋主权基金主体＋资源反担保＋开发区用款"的要素组合对标埃及、巴基斯坦、哈萨克斯坦等成功案例，且巴新资源禀赋更优；
  4. 财务上可行：融资成本较美元债节约100—200BP；木材基地（年产值25亿美元）与国家资源资产提供充足偿债保障；
  5. 执行上需管控：主权担保文件、监管审批、政局窗口为三大关键变量，需按第十章计划前置管理。

11.2 关键成功因素

  1. 主权担保文件尽快落地——一切申报工作的前提；
  2. 中国银行主承销资格确认——建议4月底前完成对接并形成书面意向；
  3. 时间窗口管理——首相任期约剩两年半，务必在两年内完成"发债＋开发区启动"，并将担保、法案、授权文件法律固化；
  4. 工作委员会与公司签约双轨并行——政府文件以委员会名义走渠道，金融法律文件以三方公司签约执行；
  5. 认购资源前置锁定——定向发行模式下，提前锁定意向认购机构是发行成功的关键；
  6. 合规底线——跨境文件、报酬安排、二级市场业务全程合规，杜绝任何形式的不正当利益输送。

11.3 建议与风险提示

建议

1. 建议三方于2026年5月前召开项目启动会，明确各里程碑责任人、时间表与费用分担；

2. 建议聘请中巴新三地律师团队，完成主权担保文件、授权文件、发行文件的合规审查；

3. 建议将巴基斯坦"多边机构部分担保"模式作为备选增信方案评估，若巴新主权担保文件在法律形式上存疑，可探讨引入亚投行/亚开行联合增信；

4. 建议发行文件中以审慎口径披露还款来源，避免过度依赖单一木材基地假设；

5. 提示：本报告所载市场数据、评级信息及案例截至2026年4月，后续市场变化（利率、政策、汇率）可能影响发行窗口与条款，建议在执行阶段动态更新。
