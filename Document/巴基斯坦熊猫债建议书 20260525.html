1.2 关键成功要素

  • 融资成本优势显著：2.5%人民币融资成本较同期美元债7-8%的利率水平节省约450-550个基点，年度利息支出可减少超千万美元
  • 增信机制创新：多边开发机构（MDB）与本土信用评级机构协同构建"双轨增信"框架，95%部分担保安排为境内市场首例，具有较强示范效应
  • 承销团队配置完备：中金公司的项目统筹与簿记能力、中国银行的跨境托管与结算网络、渣打银行的离岸投资者覆盖、红塔证券的区域分销网络形成互补
  • 发行窗口精准把握：选择在一带一路国际合作高峰论坛前后窗口期发行，市场情绪与政策导向高度契合
⚠ 现有模式的结构性局限：
  1. 规模瓶颈：72亿元人民币（约10亿美元）注册总额度，相对于巴基斯坦年均30亿美元以上的外部融资需求严重不足
  2. 担保可持续性风险：95%的多边机构担保覆盖率受限于ADB/AIIB的国别敞口额度上限，难以无限复制
  3. 缺乏制度化载体：当前以政府直接发行（总统代表授权）为主，尚未建立专门的SPV或主权基金作为循环发债平台
  4. 二级市场生态缺失：当前交易以一级市场认购持有为主，缺乏做市商机制和衍生品工具，流动性偏弱
  5. 主体-债项评级缺口：主体AA+与债项AAA之间的差距完全依赖外部担保填补，内生动能不足

3 扩大规模的三步走战略

基于首单成功经验与上述结构性局限的系统梳理，建议巴基斯坦政府采取渐进式扩量策略，分三个阶段实现从"一次性依赖担保的发债交易"向"独立可持续的国家级滚动发债平台"转型。

Phase I · 第一阶段（T+0 至 T+6个月）

快速复制期 — 在现有框架内完成扩量发行

核心目标：充分利用已建立的72亿RMB注册额度框架与中介链条，快速推进第二期、第三期发行。

执行要点：

  • 完整复用 CICC + BOC + 中诚信 + ADB/AIIB 的现有中介团队与法律框架，最大化压缩准备周期
  • 建议第二期发行规模 RMB 20-25亿元，可将资金用途拓展至中巴经济走廊（CPEC）二期重点基建项目
  • 利用首单超额认购形成的强劲市场势能（88亿需求 vs 17.5亿供给），争取将票面利率进一步压至 2.2%-2.3%
  • Matrix Bond（Matrix Bond Management）可提供的支持：募集说明书更新加速、新增投资者分销协调、路演材料优化、发行窗口时机建议
Phase II · 第二阶段（T+6至 T+18个月）

结构升级期 — 降低担保依赖，建立制度化的发债载体

（A）专项主权基金 SPV 的设立

  • 在巴基斯坦境内注册成立专项主权财富基金（SPV），100%股权归属财政部
  • 作为后续所有熊猫债发行的制度化法定载体，取代当前"总统代表"的临时性安排
  • 该 SPV 需建立符合国际标准的治理结构：董事会、审计委员会、投资委员会、合规职能
  • Matrix Bond（Matrix Bond Management）可派驻具备国际认可资质（ACCA/CPA/CFA）的 CEO 与 CFO，确保基金运营满足跨境投资者的透明度与披露要求

（B）担保比例逐步降低路径

（C）循环发债机制的建立

  • 在每期债券到期前3-6个月启动续发新债的筹备工作，以新债募集资金优先用于偿还即将到期的存量债务
  • 实现短期限债券向中长期可用资金的转换，降低再融资风险
  • 参照匈牙利模式（2017年至2024年间累计发行熊猫债超100亿元人民币）构建滚动发行的时间表模板
Phase III · 第三阶段（T+18个月以后）

平台化运营期 — 构建全功能的国家级熊猫债发行平台

规模目标：年常态化发行规模达到 RMB 50-100亿元（约 USD 10-15亿），使熊猫债成为巴基斯坦外币融资体系中的支柱型渠道。

多元化产品线：

  • 绿色熊猫债 Green Panda — 聚焦可再生能源与环境治理项目，吸引ESG主题基金配置
  • CPEC专项债券 — 募集资金定向用于走廊优先项目，强化"一带一路"叙事
  • 资源抵押债券 Resource-Backed — 以巴基斯坦矿产资源（铜、金、稀土）为底层资产支撑
  • 伊斯兰可持续债券 Sukuk-Linked — 符合伊斯兰金融原则（Sharia-compliant）的创新品种

资源银行延伸战略：推动建立自然资源资产交易平台，以巴方战略矿产资源的未来收益权或开采权作为增信抵押物，从根本上解决主权担保能力不足的问题。

衍生品收益层设计：以熊猫债存量为底层抵押品，通过持牌券商在香港交易所（HKEX）发行挂钩衍生产品（如债券ETF、利率互换结构性产品），实现服务收益与发债资金的完全隔离——发债本金100%归巴方支配，服务方收益来源于独立的资本市场操作。这一结构在全球主权熊猫债市场中尚无先例。

4 基金公司参与路径：三阶递进模式

作为基金公司，在不持有券商牌照的前提下无法担任主承销商角色，但可通过以下三种递进式路径深度参与巴基斯坦熊猫债业务链条，并在每个阶段创造差异化价值。

方式一：机构投资者（Investor Mode）— 最直接的参与方式，立即可行

标准操作流程

  1. 核实/开立银行间债券市场交易账户资格
  2. 持续关注 NAFMII 公告或主承销商发出的《申购邀请函》
  3. 簿记建档日提交投标订单（标位价格与认购数量）
  4. 获配确认后按时缴款，根据投资策略选择持有至到期或在二级市场择机卖出

Matrix Bond作为基金的竞争优势

  • 可凭借前期沟通争取 "基石投资者"身份，获得优先配售额度与价格信息
  • 通过内部网络获取更详尽的发行人尽职调查材料与路演排期
  • 可将熊猫债同时纳入多条产品线：纯债基、信用债策略、"一带一路"主题基金、ESG固收产品
  • 2.5% 的票面利率水平在当前低利率环境下对追求稳定现金流的固收产品具有较强吸引力

方式二：分销商 / 财务顾问（Distributor Mode）— 中等门槛的价值增值角色

商业模式核心：不承担主承销责任，但与主承销商团队签署《非主承销商分销协议》，协助分销一定规模的债券额度，赚取分销佣金（通常为分销额度的 0.1%-0.3%）。
  • 主动对接主承销商的债券资本市场部（DCM），表达可覆盖的潜在投资者群体规模与类型
  • 调动自身管理的客户资源网络进行推介：高净值个人专户、银行委外资金、企业年金/养老金子账户、保险 FOF 产品
  • 配合主承销商的路演行程安排，向区域内潜在投资者进行一对一路演或线上说明会
  • 收入构成：前端分销佣金 + 后端可能的客户资产管理费分成
  • 该模式下基金公司与主承销商之间形成互利共赢的合作关系——主承销商扩大了投资者基础，基金公司获得了中间业务收入与客户粘性

方式三：产品创设方（Product Creator Mode）— 高阶主动管理模式

创新方向：发起并管理专门投资于巴基斯坦熊猫债及相关品种的主题基金产品。
  • 面向合格投资者募集人民币资金，建立 "一带一路债券投资基金" 或 "新兴市场主权债精选策略"
  • 投资标的包括：巴基斯坦熊猫债存量与增量发行、其他一带一路沿线国家的在岸人民币债券、相关利率/汇率对冲工具
  • 需提前与发行人（或其SPV载体）沟通额度锁定安排，与主承销商签署定向配售协议以确保初始建仓规模
  • 从被动申购者升级为主动管理人，收入来源扩展为：管理费（AUM的0.5%-1.5%）+ 业绩报酬（超出基准收益部分的10%-20%）
  • 产品设计可沿多个差异化维度展开：期限匹配（短/中/长期）、风险偏好（稳健/平衡/进取）、主题聚焦（绿色/CPEC/资源）、合规框架（普通/伊斯兰）

5 Matrix Bond（Matrix Bond Management）的核心价值定位

5.1 已验证的一带一路主权融资方法论

Matrix Bond 管理公司目前正为一带一路沿线其他伙伴国执行主权熊猫债结构设计任务（具体国别信息受保密协议约束）。这些实践已沉淀为完整的、经过验证的方法论体系：

主权基金架构设计

SPV设立方案、治理结构搭建、IFRS/GAAP会计准则适配

5.2 收益隔离设计 — 差异化核心竞争力

根本性原则：发行所筹集的资金 100% 归属巴基斯坦政府及其指定用途，Matrix Bond不从发行本金或利息支付中提取任何形式的费用、佣金或分成。

Matrix Bond的服务回报来源于独立的、与发债资金完全隔离的衍生品市场操作：以上市熊猫债组合为底层资产，通过香港资本市场发行结构化产品所产生的管理收益与交易收入。

这一"收益隔离"结构在全球主权熊猫债发行市场中尚属首创，是 Matrix Bond相对于传统投行/券商承销模式的根本性差异点。

5.3 定向发售能力 — 精准匹配与效率优势

核心优势：Matrix Bond具备定向发售（Private Placement）的执行能力，可在银行间债券市场框架内，针对特定合格投资者群体开展非公开定向发行。相较于传统公开承销模式，这一能力带来以下结构性优势：

定向发售在巴基斯坦熊猫债扩量中的具体应用场景：

  • 第二期/第三期快速续发：在首单超额认购（>5倍）的基础上，对首轮未获足额配售或表达追加意向的机构投资者进行定向配售，利用已有的投资者关系实现T+2周内快速交割，无需重新启动全套路演流程
  • 主权基金SPV的种子资金募集：第二阶段设立专项SPV时，通过定向方式引入2-3家基石战略投资者（如一带一路专项基金、中东主权财富基金的人民币资产配置部门），以协议定价+长期持有承诺换取更有利的发行条款
  • 资源抵押类创新品种首发：Phase III推出的资源抵押熊猫债等创新产品，因底层资产结构和增信机制较为复杂，适合先以定向方式向专业机构投资者（如大宗商品对冲基金、资源类产业基金）进行首轮试点发行，验证市场接受度后再考虑扩大范围
  • 伊斯兰合规投资者群体（Sukuk-Linked）：面向中东及东南亚伊斯兰金融市场的合规投资者群体进行定向推介，该群体有独特的投资准入标准与合规审查需求，定向发售可提供定制化的法律文件与沟通方案

综上，定向发售能力使 Matrix Bond能够在传统主承销商体系之外，为巴基斯坦政府提供一个高效、灵活、低成本的并行融资通道——尤其在需要快速响应窗口机会、保护敏感信息、或对接特殊投资者群体的场景下具有不可替代的价值。
